# Постҳои канали Telegram

Ҳар пост — як файли `posts/YYYY-MM-DD-мавзӯъ.html` дар формати Telegram HTML
(`<b>`, `<i>`, `<a href>`, `<code>`, `<blockquote>`).

Нашр: Actions → «Publish Telegram post» → Run workflow (файл + ихтиёран акс).
Аввал `dry_run=true`-ро санҷед. Сирри `CHANNEL_ID` (`@username` ё `-100…`) лозим аст.
